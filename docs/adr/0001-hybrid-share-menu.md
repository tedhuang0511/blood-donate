# 分享選單採混合式:原生 Web Share API 優先,桌機退回自訂選單

活動卡片的分享圖示要支援多個分享目標(LINE、複製連結、Instagram、Threads,未來還會陸續增加)。Instagram 沒有提供可直接帶文字/連結開啟分享畫面的網址,只有透過瀏覽器原生 Web Share API(`navigator.share`)才能讓使用者在系統分享選單中選擇 IG。因此決定:支援 `navigator.share` 的裝置(多為手機瀏覽器)一律叫出系統原生分享選單;不支援的裝置(多為桌機瀏覽器)才退回顯示自訂下拉選單,選單內只放「有辦法用網址直接處理」的目標(LINE、Threads、複製連結),**刻意不放 Instagram**——與其做出一個「複製文字後手動貼上」的陽春假分享體驗,不如讓 IG 分享只在真正原生支援時出現。

也考慮過「完全自訂選單、不論裝置一律顯示同一組按鈕」的做法,但這樣所有裝置都要接受 Instagram 分享只是「複製+手動貼上」的妥協體驗;放棄此案,選擇讓多數分享情境(手機)得到最順的原生體驗。

代價:同一顆分享圖示在手機和桌機上行為不同(選單內容不一樣),未來排查相關 bug 或新增分享目標時需要意識到這個分歧。
